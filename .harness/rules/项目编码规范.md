# 项目编码规范

## Python 代码规范

### 版本要求
- Python >= 3.11
- 使用 `async`/`await` 异步编程

### 类型提示
```python
# 正确
def process(user_id: str) -> list[dict[str, Any]]:
    ...

# 错误
def process(user_id) -> List[Dict]:
    ...
```

### 类型规范
| 场景 | 正确写法 | 错误写法 |
|------|----------|----------|
| 可选字符串 | `str \| None` | `Optional[str]` |
| 列表 | `list[str]` | `List[str]` |
| 字典 | `dict[str, Any]` | `Dict[str, Any]` |
| 集合 | `set[int]` | `Set[int]` |

## Pydantic 模型规范

### 模型定义
```python
from pydantic import BaseModel, ConfigDict, Field
from uuid_extensions import uuid7str

class AgentView(BaseModel):
    model_config = ConfigDict(
        extra='forbid',
        validate_by_name=True,
        validate_by_alias=True,
    )

    id: str = Field(default_factory=uuid7str)
    name: str
    status: str = "active"
```

### 字段验证
```python
from Annotated import AfterValidator

def validate_positive(v: int) -> int:
    assert v > 0, "必须大于 0"
    return v

class PriceField(BaseModel):
    amount: Annotated[int, AfterValidator(validate_positive)]
```

## ID 生成规范

```python
from uuid_extensions import uuid7str

# 使用 default_factory
id: str = Field(default_factory=uuid7str)
```

## 日志规范

### 日志方法命名
- 前缀 `_log_` 用于日志方法
- 将日志逻辑与主逻辑分离

```python
class AgentService:
    def _log_request(self, request: Request) -> None:
        logger.info(f"Request: {request.action}")

    async def execute(self, request: Request) -> Response:
        self._log_request(request)
        # 主逻辑
```

### 日志级别
- DEBUG: 调试信息
- INFO: 一般信息
- WARNING: 警告
- ERROR: 错误

## 核心约束

### 强制约束
2. **外部服务调用**：必须设置超时和降级
3. **错误处理**：所有外部调用必须 try-catch 处理
4. **ID 字段**：使用 `uuid7str` 生成

### 代码组织
- 主逻辑放在 `service.py` 文件
- Pydantic 模型放在 `views.py` 文件
- 事件定义放在 `events.py` 文件
- 使用 `_log_` 前缀命名日志方法

## 分层编码规范

### 表现层 (Controller)
- 参数校验
- 异常处理
- 响应格式化

### 应用层 (Service)
- 业务逻辑编排
- 事务管理
- 校验规则执行

### 领域层 (Domain)
- 核心业务逻辑
- 业务规则
- 状态管理

### 基础设施层 (Adapter)
- 外部服务调用
- 协议实现
- 数据转换

## 质量门禁

### 必须验证
1. 代码编译通过
2. 类型检查通过 (`uv run pyright`)
3. 格式化检查通过 (`uv run ruff check --fix`)
4. 测试覆盖率 >= 80%

### 禁止项
- console.log 语句（使用 logger 替代）
- 硬编码值
- 未处理的异常
- 单字母变量名

## 文件大小控制
- 单文件不超过 800 行
- 单函数不超过 50 行
- 嵌套层级不超过 4 层
