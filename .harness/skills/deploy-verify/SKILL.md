# 部署验证

## 验证点

| 验证项 | 内容 |
|--------|------|
| 依赖完整性 | 依赖已声明、版本兼容、无冲突 |
| 配置正确性 | 环境变量、配置文件、秘钥 |
| 环境一致性 | 测试与生产环境一致 |
| 启动验证 | 服务启动、健康检查、基础功能 |

## 检查清单

- [ ] 依赖安装完成
- [ ] 配置已同步
- [ ] 数据库迁移完成
- [ ] 服务启动成功
- [ ] 健康检查通过
- [ ] 基础功能验证

## 报告格式

```markdown
# 部署验证报告

## 验证摘要
- 状态: SUCCESS/FAILED

## 验证详情
| 检查项 | 状态 | 详情 |
|--------|------|------|
```

## 质量门禁脚本

阶段完成后，可使用脚本验证产出物：

```bash
python scripts/check_quality_gate.py <change-id>
```

**检查项**:
- deployment/deploy_report_v*.md 存在
