# 项目分析

## 分析维度

| 维度 | 内容 |
|------|------|
| 项目结构 | 目录组织、模块划分 |
| 依赖关系 | 内部/外部依赖、循环依赖 |
| 模块划分 | 核心/边界/共享模块 |
| 架构模式 | 设计模式、扩展性评估 |

## 分析命令

```bash
# 结构分析
find . -type f -name "*.py" | head -20

# 依赖分析
uv tree

# 类型分析
uv run pyright --stats
```
