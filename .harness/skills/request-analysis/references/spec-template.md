```markdown

## 1. 概述
[需求背景和目标]

## 2. 输入
| 参数 | 类型 | 来源 | 描述 |
|------|------|------|------|
| xxx | string | 用户输入 | 描述 |

## 3. 输出
| 返回值 | 类型 | 格式 | 描述 |
|--------|------|------|------|
| xxx | object | JSON | 描述 |

## 4. 功能列表
- [ ] 功能点1
- [ ] 功能点2

## 5. 边界条件
- 边界1
- 边界2

## 6. 异常处理
| 异常 | 处理方式 |
|------|----------|
| xxx | 描述 |
```
