# 评审检查清单

## Plan Review 详细检查项

### 完整性检查
- [ ] 输入参数已定义
- [ ] 输出返回值已定义
- [ ] 边界条件已识别
- [ ] 异常场景已考虑

### 一致性检查
- [ ] tasks与spec功能匹配
- [ ] 任务依赖关系正确
- [ ] 无遗漏的功能点

### 可执行性检查
- [ ] 任务粒度适中
- [ ] 验收标准可测试
- [ ] 无循环依赖

## Execution Review 详细检查项

### 代码正确性
- [ ] 逻辑符合需求
- [ ] 边界条件处理正确
- [ ] 异常处理完善

### 规范遵循
- [ ] 遵循8分层规范
- [ ] 类型提示完整
- [ ] 错误处理规范

### 安全性检查
- [ ] 无硬编码秘钥
- [ ] 输入验证完善
- [ ] 无SQL注入风险

### 性能检查
- [ ] 无N+1查询
- [ ] 适当缓存
- [ ] 索引合理

## 前端专项评审检查项

### 校验逻辑完备性
- [ ] 空集合不能通过提交校验
- [ ] 子项内容逐条校验（非仅校验数量）
- [ ] 格式校验含边界值（端口范围、字符串长度）
- [ ] 关联数据双向一致性校验
- [ ] 校验前确保依赖数据已加载（非依赖本地缓存）
- [ ] 前置条件（sessionId 等上下文）在操作前校验
- [ ] 部分空值拦截（非仅全空行）

### 布局稳定性
- [ ] 嵌套 flex 容器添加 `min-h-0` 约束
- [ ] 内容区域不会无限延伸
- [ ] 滚动行为正确（overflow-y-auto）


## 测试评审检查项

### 覆盖率
- [ ] 关键路径已覆盖
- [ ] 边界条件已测试
- [ ] 异常场景已测试

### 有效性
- [ ] 测试真正执行代码
- [ ] 断言有意义
- [ ] 无假阳性

### 真实性
- [ ] 使用真实数据
- [ ] 场景合理
