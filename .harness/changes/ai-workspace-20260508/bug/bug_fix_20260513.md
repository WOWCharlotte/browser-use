## 1. BUG-001: 前端 API 地址未配置

### 问题描述

前端无法正确连接到后端服务，API 请求地址为空或指向错误地址。

### 原因分析

1. `frontend/` 目录缺少 `.env.local` 文件
2. `api.ts` 中使用 `process.env.NEXT_PUBLIC_API_URL`，但该环境变量未设置
3. 默认回退值为 `"http://localhost:8888/api"`，但 Next.js 在构建时可能无法正确解析

### 修复方案

创建 `frontend/.env.local` 文件，内容如下：

```
NEXT_PUBLIC_API_URL=http://localhost:8888/api
```

### 修复文件

| 文件 | 操作 |
|------|------|
| `frontend/.env.local` | 新增 |

### 验证方法

1. 重启前端开发服务器 (`cd frontend && pnpm dev`)
2. 打开浏览器控制台，检查网络请求
3. 确认 API 请求发往 `http://localhost:8888/api/*`

## 3. BUG-003: 点击删除未发生真实 API 调用

### 问题描述

`handleDelete` 函数没有 try-catch 包裹，可能导致 API 调用失败时前端状态不一致。

### 修复方案

在 `Sidebar.tsx` 的 `handleDelete` 函数中添加 try-catch：

```typescript
const handleDelete = async (sessionId: string) => {
    try {
        await deleteSession(sessionId);
        setSessions((prev) => prev.filter((s) => s.id !== sessionId));
        // ... 切换逻辑
    } catch (e) {
        console.error("Failed to delete session:", e);
    }
};
```

## 5. BUG-004: page.tsx useEffect 条件导致初始化循环

### 问题描述

`page.tsx` 中 `useEffect` 的条件 `!currentSessionId && !isInitialized` 导致：
1. 首次渲染时 `currentSessionId` 为空字符串 `""`，`!currentSessionId` 为 `true`
2. 创建 session 后 `setCurrentSessionId` 触发重新渲染
3. 但 `isInitialized` 被设为 `true`，导致 useEffect 不再执行
4. 可能导致 session 创建被跳过或多次调用

### 修复方案

修改 `page.tsx` 的 `useEffect`：

```typescript
useEffect(() => {
  if (!isInitialized) {
    setIsInitialized(true);
    createSession()
      .then((session) => {
        setCurrentSessionId(session.id);
      })
      .catch((err) => {
        console.error("Failed to create session:", err);
      });
  }
}, [isInitialized]);
```

### 修复文件

| 文件 | 操作 |
|------|------|
| `frontend/src/app/page.tsx` | 修改 |

## 6. BUG-005: CORS 错误 + PUT /sessions 返回 500

### 问题描述

1. CORS 错误：`Access-Control-Allow-Origin` header missing
2. PUT 请求返回 500 Internal Server Error

### 原因分析

后端 `session_service.py` 使用 `dict(row)` 转换 aiosqlite.Row，但 aiosqlite.Row 不支持直接 dict() 转换，导致 `_row_to_dict()` 函数返回错误格式的数据。

### 修复方案

添加 `_row_to_dict()` 辅助函数，正确转换 aiosqlite.Row：

```python
def _row_to_dict(row) -> dict:
    """Convert aiosqlite.Row to dict properly."""
    if hasattr(row, '_asdict'):
        return row._asdict()
    return dict(zip([c[0] for c in row.keys()], row))
```

| `backend/app/services/session_service.py` | 修改 |
