# 数据持久化与历史展示 - 思维导图

```mermaid
tree
root[数据持久化与历史展示]
  core[核心目标]
    goal1[消息持久化存储]
      save_user[保存用户初始消息]
      save_agent[保存 Agent 每步回复消息]
    goal2[截图/状态历史持久化]
      db_states_history[修改 browser_states 为 1对多 结构]
      save_steps[保存每步的 URL、标题、截图]
    goal3[历史恢复与展示]
      chat_history[会话切换加载历史消息]
      browser_history[会话切换加载历史截图]
  modules[涉及模块]
    backend[后端: backend/app/]
      db[数据库层]
        database_py[database.py: init_db/重构 browser_states 表]
      service[服务层]
        session_service_py[session_service.py: 读写 messages 与 browser_states]
        agent_service_py[agent_service.py: 在 step_end 拦截并写入数据]
      api[接口层]
        agui_py[agui.py: 拦截用户消息]
        sessions_py[sessions.py: 新增获取历史截图接口]
    frontend[前端: frontend/src/]
      api_ts[lib/api.ts: 定义 fetchBrowserStates 接口]
      components[组件层]
        chat_window[ChatWindow.tsx: 切换会话调用 setMessages 渲染历史]
        page_tsx[page.tsx: 切换会话拉取历史截图并支持 live 增量合并]
  db_schema[数据库设计]
    sessions[sessions: id, title, created_at, updated_at]
    messages[messages: id, session_id, role, content, attachments, created_at]
    browser_states[browser_states: id, session_id, url, title, screenshot, created_at]
  risks[潜在风险]
    data_size[截图数据量过大]
      mitigation[数据库使用 SQLite, 截图为 base64, 本地轻量开发无虞]
    schema_migration[表结构破坏性变更]
      mitigation[在 init_db 中自动检测并 Drop 重建空的 browser_states 表]
```
